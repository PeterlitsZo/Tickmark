## 设计方向

沿用 Tickmark 暖白和深绿，压缩重复日期信息；采用底部 Calendar / Todos 两个 tabs，分别承载时间记录和全局待办。系统字体、等宽数字、正文 16 pt 左右，次要信息 12–13 pt；关键点击区域至少 44×44 pt（Android 优先 48）。分类使用浅底、深文字、名称与色点，不能只靠颜色区分。

1. **Calendar tab**：月份/Today/新增、周条、简短时区；单日时间轴占主体。右上溢出菜单包含刷新与分类管理。底部固定 Calendar / Todos 导航，图标配文字，选中态有背景和字重变化；默认进入 Calendar。不再放待办摘要或可展开待办区。
2. **Todos tab**：独立完整页面，顶部标题、未完成数量、刷新和新增输入固定，列表占剩余区域并独立滚动。点标题原位编辑，行菜单提供删除；完成项可折叠并允许重开，设计图展示展开态。Todos 是全局列表，不受日历日期影响。切换 tab 保留各自滚动位置、选中日期、输入草稿、完成项展开状态与结果不确定状态，不触发保存或放弃确认。
3. **记录编辑态**：保留现有 BottomSheet；标题、分类、起止、时长及保存按阅读顺序排列。分类选择进入同一面板的子状态，管理入口可返回原草稿；不叠加第二层底部抽屉。编辑面板覆盖底部 tabs，需先保存或关闭后再切换，关闭时仍遵循脏草稿保护。长标题、键盘和大字体时正文滚动，保存固定于键盘上方。Todos 键盘弹出时隐藏 tab bar，为输入留空间；收起键盘后恢复导航且不清空草稿。
4. **分类管理态**：通过 Expo Router 独立页面展示，返回保留日历/编辑草稿。列表可改名、改色、新增、删除；八色均有文字标签、选中勾号。重名显示 ID；不展示未经服务端支持的全历史引用数量。引用中删除的服务端拒绝就地解释。
5. **异常态**：读取失败不清空已有内容；离线显示缓存且禁写；写入结果不确定保留草稿，给出 Check status；检查未能确认时再显式开放重试并说明重复/覆盖风险。不可把刷新后的同名记录自动当作此次成功。

时间块保留类别标签在标题左侧的既有设计；短块标签尺寸不变，长名称截断，完整信息在详情与可访问标签中。选中以轮廓与手柄表达。所有手势都有点按编辑替代入口。

## 功能与数据规则

- Todos：列表、新增、改标题、完成/重开、确认删除；状态为 `OPEN` / `COMPLETED`；PATCH 只发送变化字段。标题保留原始空格，1–500 Unicode scalar。先取完整列表本地分组，不增加筛选表达式 UI。
- 分类：GET/POST/PATCH/DELETE，名称遵循服务端 trim 与 1–100 Unicode scalar；颜色仅发送 RED/ORANGE/YELLOW/GREEN/BLUE/PURPLE/PINK/GRAY。未来未知颜色中性展示，改名不能覆盖它。
- 记录：响应保留字符串 category_id；新建、编辑、移动、缩放、预览、输入比较、脏状态、缓存与不确定保存匹配全部覆盖分类。只有分类变化也必须能保存。ID 不转 Number。
- 新建默认：本机上次成功创建的有效分类 → 最小数字 ID → 已确认空列表时允许服务端创建 Default/GRAY。加载中/失败不是空列表。偏好按 API origin 隔离，选用 SDK 58 兼容的持久化方案；仅成功创建更新，编辑/取消/失败不更新；存储失败不阻断保存。
- 分类被外部删除时，保留草稿并要求显式重选；映射缺失时保留时间项中性展示，不伪装成 Default。分类变更更新共享缓存，已加载日期立即反映。
- 保留 DST、跨日裁剪、秒精度、重叠、零时长、离线禁写与前台/重连刷新。无持久化离线队列、无自动重试写入、无实时订阅承诺。
- Todos 和时间项仍独立，不加入“待办转记录”、截止日期、任务分类、提醒或统计等 API 尚未支持的能力。

## 实施顺序

### 1. API 与数据保护

先核对 SDK 58 官方版本文档及当前依赖，再触及 Expo / React Native API。抽取 `mobile/src/api/client.ts`，加入响应校验、超时、取消及一致错误；将 PATCH/DELETE 的结果不确定纳入处理。新增 todos/categories API 与共享 Query keys。修复 Entry 类型及所有写入、拖拽和恢复路径，优先防止编辑已有分类记录时改变其分类。

预计修改 `api/entries.ts`、`features/entries/{EntriesProvider,useEntryEditor,useEntryMutations,entriesQueries}.tsx/ts`、`features/calendar/useTimelineInteraction.ts`、`lib/time.ts` 的相关数据比较与校验。

### 2. 分类与偏好

新增 `features/categories/` 查询、变更、颜色映射、选择器、管理与偏好存储。接入 EntryForm / EntryEditor / TimeBlock；增加 Expo Router 分类页面。保留 unknown color，确认服务端被引用删除错误的 reason 映射；偏好读取结束前不得覆盖用户手动选择。

### 3. 底部导航与待办

通过 Expo Router 建立 Calendar / Todos 双 tab 布局，分类管理放在 tabs 外的根 Stack，保留已有日历 URL 和旧 `/entries` 跳转语义。先核对 SDK 58 版本文档再确定具体 Tabs API，不手写平行导航系统。

新增 `features/todos/`，实现创建、编辑、完成、重开、完成项折叠和确认删除。共享 Query、草稿与请求跟踪状态放在 tab navigator 之上；不能依赖页面是否保持挂载来保存草稿。切 tab、换日及返回分类管理不销毁草稿或结果不确定状态。两个 tab 的滚动独立；重新点当前 tab 不自动回顶或清空表单。前台与重连刷新不覆盖未保存输入。分类页面返回原 tab/编辑上下文；Android 返回先处理键盘/编辑子状态，再返回上一层，根页面按导航历史返回。

### 4. 视觉与可访问性

调整 DateHeader、CalendarScreen、theme 与块内容；完成键盘、safe area、Android 返回顺序（先子选择器、再草稿关闭保护）、屏幕阅读器名称、状态播报、焦点恢复。小屏/大字时允许面板接近全屏，为编辑面板、键盘与底部导航分别处理安全区域，避免重复底部留白。

### 5. 验证与交付

不新增测试文件。实现完成后运行既有 `npm --prefix mobile run typecheck`、`npm --prefix mobile run lint`、`npm --prefix mobile run export`；依赖变化时检查 Expo 兼容性。使用已应用分类迁移的隔离本地 API，手动检查 iOS/Android，不能用生产数据做写入验证。

验收覆盖：
- Todo 全流程、完成项重开、切 tab/切日期保留草稿与滚动位置、输入法与键盘遮挡、长标题。
- 分类全流程、八色、重名、未来颜色、跨日期引用拒删、空库 Default、读取失败。
- 上次成功创建的类别重启后恢复；记忆类别被删除/切换 API origin/存储失败的回退。
- 仅改分类、拖动和缩放不改分类，分类参与不确定保存匹配；读写超时、响应无法解析、404、离线恢复。
- 320/390/430 pt 宽、大字体、窄屏键盘、VoiceOver/TalkBack、Android 返回及前后台切换。
- 原时间轴长按、边缘滚动、跨日、秒精度、DST、重叠与零时长无回归。
